# Весёлый сущ

Небольшая браузерная игра о загадочном существе, которое бежит навстречу приключениям, собирает вкусности и избегает забавных препятствий.

## Идея

Игрок управляет Весёлым сущом: помогает ему продержаться как можно дольше, набрать очки и установить новый рекорд. Игра должна быть простой, доброй и немного абсурдной.

## Первая версия

- движение и прыжок;
- препятствия и предметы;
- подсчёт очков;
- лучший результат;
- управление с клавиатуры и телефона.

## Технологии

- PHP / Laravel;
- MariaDB;
- Blade, Livewire и Alpine.js;
- HTML5 Canvas для игрового поля.

Проект создаётся как практическое знакомство с Codex, разработкой, тестированием и развёртыванием веб-приложения.
